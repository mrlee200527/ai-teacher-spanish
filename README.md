# AI Teacher — AI语言老师项目

一个用AI老师带领集体课堂学习的语言学习平台。从西班牙语切入，未来扩展到全语种。

## 🎯 项目目标

MVP目标：帮助零基础学员快速达到西班牙语A2水平（听说读写）

长期愿景：西班牙语 → 全语种 → "年轻人的数字夜校"（任何技能）

## 📚 课程体系

### Week 1：语音速成 + 语法基础

| Day | 主题 | 目标 |
|-----|------|------|
| Day 1 | 语音速成营（1天学完原计划7天） | 掌握全部字母发音规则 |
| Day 2 | 动词 ser/estar + 名词性别 | 能说"我是中国人" |
| Day 3 | 动词 tener + 数字1-10 | 能说"我有X个朋友" |
| Day 4 | 现在时规则变位（-ar结尾动词） | 能说"我讲西班牙语" |
| Day 5 | 现在时规则变位（-er/-ir结尾动词） | 能说"我学/我住" |
| Day 6 | 情境词汇：家庭 + 职业介绍 | 能描述自己的家庭 |
| Day 7 | 综合测试 + 自我介绍实战 | 能完整自我介绍 |

### 课程原则
- 语音先行：Day 1必须完成，不完成不进入Day 2
- 每天15-20分钟：任务量设计为可完成
- 敢开口优先：发音不苛求音素（大舌音/清浊音标为可选）
