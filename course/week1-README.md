# Week 1：西班牙语入门课程

## 📋 课程概述

**目标**：第1周能开口说话，第7天能做真实自我介绍（名字/国籍/年龄/家庭/职业）

**时间安排**：
- Day 1：语音速成营（6段×15分钟，总计1.5-2小时，一次学完）
- Day 2-7：语法基础 + 实用词汇

**打卡机制**：
- 完成当天任务后改昵称进阶（🐣→🐼→🦊→🐯→🦁→🐉）
- Day 1必须完成才能进入Day 2（不完成第二天需补完）

---

## 🗓️ 课程安排

| 日期 | 主题 | 目标 | 打卡 |
|------|------|------|------|
| **Day 1** | 语音速成营 | 掌握全部字母发音规则，能读任何西语单词 | [名字] 🐼 |
| **Day 2** | 动词 ser/estar + 名词性别 | 能说"我是中国人" | [名字] 🦊 |
| **Day 3** | 动词 tener + 数字1-10 | 能说"我有X个朋友" | [名字] 🐯 |
| **Day 4** | 现在时规则变位（-ar结尾动词） | 能说"我讲西班牙语" | [名字] 🦁 |
| **Day 5** | 现在时规则变位（-er/-ir结尾动词） | 能说"我学/我住" | [名字] 🐯 |
| **Day 6** | 情境词汇：家庭 + 职业介绍 | 能描述自己的家庭 | [名字] 🐯 |
| **Day 7** | 综合测试 + 自我介绍实战 | 能完整自我介绍（名字/国籍/年龄/家庭/职业） | 🎉 完成！ |

---

## 📚 学习原则

1. **语音先行**：Day 1必须完成，不完成不进入Day 2
2. **每天15-20分钟**：任务量设计为可完成，降低放弃率
3. **即时反馈**：完成当天任务后改昵称，有成就感
4. **社交绑定**：群内互见进度，有压力
5. **敢开口优先**：发音不苛求音素（大舌音/清浊音标为可选挑战）

---

## 🎯 Week 1 结束目标

完成Week 1后，学生应该能够：

- ✅ 读出任何西语单词（即使不懂意思）
- ✅ 用西语做自我介绍（名字、国籍、年龄、家庭、职业）
- ✅ 掌握核心动词：ser/estar/tener
- ✅ 掌握基础动词变位（-ar/-er/-ir）
- ✅ 能说出简单句子（"我是中国人"、"我有3个朋友"等）
