## 第1段：元音基础（15分钟）

### 学习内容

西语有5个元音，发音规则固定，学会就能读任何单词。

| 元音 | 发音特点 | 中文类比 |
|------|---------|---------|
| **a** | 张大嘴，短促有力 | 像"啊" |
| **e** | 嘴角向两边拉开 | 像"诶"（微笑时说） |
| **i** | 咧嘴，嘴角向两边拉 | 像"一" |
| **o** | 圆嘴 | 像"喔" |
| **u** | 嘟嘴 | 像"乌" |

### 例词练习

跟读以下单词（每词读3遍）：

1. **mamá**（妈妈）- ma-má
2. **papá**（爸爸）- pa-pá
3. **papá**（爸爸）- pa-pá
4. **mamá**（妈妈）- ma-má
5. **papá**（爸爸）- pa-pá
6. **mamá**（妈妈）- ma-má

## 第2段：辅音（1）——鼻音与流音（15分钟）

### 学习内容

| 辅音 | 发音特点 |
|------|---------|
| **m** | 双唇闭，从鼻音发出 |
| **n** | 舌尖抵上齿，从鼻音发出 |
| **p** | 双唇爆破，送气 |
| **l** | 舌尖抵上齿，舌尖两边出气 |
| **ñ** | 特殊字母，读"ny"音，像西班牙语的"年" |

### 例词练习

跟读以下单词（每词读3遍）：

1. **mamá**（妈妈）- ma-má

4. **papá**（爸爸）- pa-pá

## 第3段：辅音（2）——爆破音（15分钟）

### 学习内容

西语有清浊音的区别，这是和中文不同的地方。

| 辅音 | 类型 | 发音特点 |
|------|------|---------|
| **b** | 浊音 | 双唇闭，声带振动 |
| **d** | 浊音 | 舌尖抵上齿，声带振动 |
| **g** | 浊音 | 软腭音，声带振动 |
| **p** | 清音 | 双唇爆破，送气 |
| **t** | 清音 | 舌尖抵上齿，送气 |
| **k** | 清音 | 软腭爆破，送气 |

### 例词练习

跟读以下单词（每词读3遍）：

1. **gato**（猫）- ga-to
2. **pato**（鸭子）- pa-to
3. **taza**（杯子）- ta-za
4. **dedo**（手指）- de-do
5. **bota**（靴子）- bo-ta
6. **casa**（房子）- ca-sa

### AI推送消息（第3段）

```
📢 Day 1：第3段 爆破音

接下来学习爆破音，注意清浊音的区别！

📹 清浊音区别：
- b/d/g（浊音）：声带振动，不送气
- p/t/k（清音）：送气，声带不振动

💡 例词练习（每词读3遍）：
1. gato（猫）
2. pato（鸭子）
3. taza（杯子）
4. dedo（手指）
5. bota（靴子）
6. casa（房子）

```

## 第4段：辅音（3）——摩擦音（15分钟）

### 学习内容

| 辅音 | 发音特点 |
|------|---------|
| **f** | 上齿咬下唇 |
| **s** | 舌尖靠近上齿，气流从牙缝出来 |
| **ch** | 读"tʃ"音，像中文的"吃" |
| **j** | 读"h"音，像德语的"h" |
| **h** | 不发音！看到h跳过即可 |

### 例词练习

跟读以下单词（每词读3遍）：

1. **chica**（女孩）- chi-ca
2. **hijo**（儿子）- i-jo（h不发音）
3. **hola**（你好）- o-la（h不发音）
4. **fiesta**（派对）- fies-ta
5. **sí**（是）- sí
6. **no**（不）- no

## 第5段：辅音（4）——颤音与其他（15分钟）

### 学习内容

| 辅音 | 发音特点 |
|------|---------|
| **r** | 轻颤音，舌尖轻弹上腭 |
| **rr** | 重颤音，舌尖快速颤动（单词开头或双写） |
| **ll** | 读"j"音，像英文的"j" |
| **y** | 读"j"音，像英文的"j" |
| **q** | 读"k"音，只出现在"que"、"qui"组合中 |

### 例词练习

跟读以下单词（每词读3遍）：

1. **rojo**（红色）- ro-jo
2. **perro**（狗）- pe-rro
3. **llama**（火焰）- ya-ma
4. **yo**（我）- yo
5. **queso**（奶酪）- que-so
6. **hasta**（直到）- has-ta

**进阶挑战（可选）：颤音**

颤音是西语的特色，但不用焦虑。初学者可以用"r"代替"rr"，不会影响沟通。

- **r**：舌尖轻弹上腭（像英文的"r"）
- **rr**：舌尖快速颤动（像德语的"r"）

### AI推送消息（第5段）

```
📢 Day 1：第5段 颤音与其他

接下来学习颤音和其他辅音，颤音是进阶挑战（可选）！

📹 发音特点：
- r：舌尖轻弹上腭，像英文的"r"
- rr：舌尖快速颤动，像德语的"r"
- ll/y：读"j"音，像英文的"j"
- q：读"k"音，只出现在"que"、"qui"组合中

💡 例词练习（每词读3遍）：
1. rojo（红色）
2. perro（狗）
3. llama（火焰）
4. yo（我）
5. queso（奶酪）
6. hasta（直到）

🌟 进阶挑战（可选）：
颤音是西语的特色，初学者可以用"r"代替"rr"，不影响沟通！
```
