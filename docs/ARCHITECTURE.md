# AI Teacher 系统架构文档

## 系统概述

AI Teacher 是一个西班牙语学习系统，帮助零基础学生快速达到A2水平（听说读写）。

### 核心功能

1. **课程学习**：学生通过网站学习课程内容（课文 + 练习题）
2. **AI批改**：大语言模型自动批改练习题并提供反馈
3. **进度追踪**：记录学生学习进度，支持60%完成率解锁机制
4. **微信集成**：微信机器人推送学习链接、检测完成率、提醒学生

---

## 技术架构

### 前端

- **技术栈**：原生 HTML/CSS/JavaScript
- **页面**：
  - `index.html`：首页（登录 + 课程列表）
  - `course.html`：课程学习页
  - `progress.html`：学习进度页

### 后端

- **技术栈**：Python + Flask
- **核心模块**：
  - `app.py`：Flask应用主入口
  - `config.py`：应用配置（Session、数据库、CORS）
  - `database/`：数据库管理（SQLite）
  - `llm/`：大语言模型集成（小米大模型）
  - `routes/`：API路由

### 数据库

- **类型**：SQLite
- **表结构**：
  - `students`：学生信息
  - `courses`：课程内容
  - `exercises`：练习题
  - `submissions`：练习提交记录
  - `progress`：学习进度
  - `wrong_answers`：错题本

## 核心流程

### 1. 登录流程

```
用户输入用户名 + API密钥
  ↓
POST /api/login
  ↓
创建或查找学生 → 存储到数据库
  ↓
保存到Session（user_id, username, api_key）
  ↓
返回登录成功
```

**安全说明**：
- API密钥存储在Session中（服务器端内存）
- Session过期后密钥自动清除
- 不在数据库中存储API密钥

### 2. 学习流程

```
学生登录 → 查看课程列表
  ↓
点击课程 → 加载课程内容 + 练习题
  ↓
学习课文 → 完成练习题
  ↓
提交答案 → AI批改 → 显示反馈
  ↓
所有练习完成 → 标记课程完成
  ↓
检查完成率 → 达到60%则解锁下一环节
```

### 3. 微信机器人集成流程

```
微信机器人定时触发
  ↓
GET /api/wechat/push/{student_id}
  ↓
检查是否有新课程
  ↓
推送到微信群
```

```
学生完成课程 → POST /api/courses/{id}/complete
  ↓
计算整体完成率
  ↓
达到60% → 自动解锁下一课程
```

```
定时任务 → GET /api/wechat/remind
  ↓
查找未完成的学生
  ↓
推送提醒消息
```

## 记忆管理方案

### Session存储（服务器端）

- **内容**：登录状态、用户ID、用户名、API密钥
- **过期时间**：2小时（可配置）
- **优点**：相对安全，重启后自动清除

### LocalStorage（浏览器端）

- **内容**：
  - 当前课程ID
  - 练习答案（未提交的草稿）
  - 用户偏好（如上次登录的用户名）
- **优点**：刷新页面不丢失
- **缺点**：清空浏览器缓存后丢失

### 数据库（SQLite）

- **内容**：
  - 学生信息
  - 课程内容
  - 练习题
  - 学习进度
  - 错题本
  - 练习提交记录
- **优点**：持久化存储
- **缺点**：无法临时存储（如草稿）

### 刷新/切换页面记忆流程

```
用户打开网站
  ↓
检查Session（是否有登录）
  ↓ 有登录 → 进入首页
  ↓ 无登录 → 跳转登录页
  ↓
用户进入课程页
  ↓
从LocalStorage恢复上次学习的位置
  ↓
从数据库加载课程内容
  ↓
用户做练习
  ↓
答案存LocalStorage（防止刷新丢失）
  ↓
点击提交
  ↓
答案存数据库 + LocalStorage清空
  ↓
用户刷新页面
  ↓
从数据库恢复批改结果
```
